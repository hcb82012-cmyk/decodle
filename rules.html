Game Rules

home

Standard Mode

  1. Greens are in the correct position
  2. Yellows are in the wrong position but in the word
  3. Reds do not appear in the word
  4. You have 6 tries to guess the word
  5. Each word is 5 letters long
  6. You get 1 hint
  7. A is x B is x + 1

Minute Mode

  1. Same rules as standard mode apply
  2. You only have 1 minute

Hard Mode

  1. Same rules as standard mode apply
  2. You only get 4 numbers

Hard Minute Mode

  1. Same rules as standard mode apply
  2. You only have 1 minute
  3. You only get 4 numbers

Dev Mode

  1. Same rules as standard mode apply
  2. The answer is logged in the console
